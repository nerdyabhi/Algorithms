# [Longest Substring Without Repeating Characters](https://leetcode.com/problems/longest-substring-without-repeating-characters/)

Given a string `s`, find the length of the longest substring without repeating characters.

---

### **1. Brute Force Approach**

**Idea**:  
Check every possible substring starting from each character and keep track of characters using a map to check if there are any repeating characters.

**Steps**:
1. Initialize `ans = 0` to store the maximum length of substring without repeating characters.
2. Iterate over each character in the string using an index `i`.
3. Use an unordered map `mp` to track characters of the current substring starting from `i`.
4. For each starting character, keep checking each subsequent character using another index `j`.
5. If a character `s[j]` is not in the map, add it and continue.
6. If it is already present, break the loop (as it’s repeating).
7. Update `ans` with the maximum length found so far.
8. Return `ans`.

**Code**:

```cpp
class Solution {
public:
    int lengthOfLongestSubstring(string s) {
        if (s.length() == 0) return 0;

        int ans = 0;

        for (int i = 0; i < s.length(); i++) {
            unordered_map<char, bool> mp;
            int len = 0;

            for (int j = i; j < s.length(); j++) {
                if (!mp[s[j]]) {
                    len++;
                    mp[s[j]] = true;
                } else {
                    break;
                }
            }
            ans = max(ans, len);
        }

        return ans;
    }
};
```

**Time Complexity**: O(N^2)  
**Space Complexity**: O(min(N, M)), where N is the length of the string and M is the character set size.

---

### **2. Better Approach (Sliding Window using Hash Map)**

**Idea**:  
Use two pointers `i` and `j` to create a sliding window, maintaining a map to track character frequency within the window.

**Steps**:
1. Initialize two pointers `i` and `j` at the beginning of the string and `ans = 0` to store the result.
2. Iterate over the string with pointer `j`.
3. Keep track of character frequencies using a map `mp`.
4. If a character appears more than once (`mp[s[j]] > 1`), move the starting pointer `i` right until all characters in the window are unique.
5. Update the maximum length (`ans = max(ans, j - i + 1)`).
6. Return `ans`.

**Code**:

```cpp
class Solution {
public:
    int lengthOfLongestSubstring(string s) {
        int i = 0, j = 0, ans = 0, n = s.length();
        unordered_map<char, int> mp;

        for (j = 0; j < n; j++) {
            mp[s[j]]++;
            while (i < n && mp[s[j]] > 1) {
                mp[s[i]]--;
                i++;
            }

            ans = max(ans, j - i + 1);
        }

        return ans;
    }
};
```

**Time Complexity**: O(N)  
**Space Complexity**: O(min(N, M))

---

### **3. Optimal Approach (Sliding Window with Index Map)**

**Idea**:  
Track the last index of each character using a map and move the starting pointer `i` directly to the right of the last occurrence of the repeated character.

**Steps**:
1. Initialize two pointers `i` and `j`, and `ans = 0`.
2. Use a map `mp` to store the last index of each character.
3. Iterate over the string with pointer `j`.
4. If a character `s[j]` is found in the map and its last occurrence is within the current window (`mp[s[j]] >= i`), move `i` to `mp[s[j]] + 1`.
5. Update the last occurrence of `s[j]` in the map (`mp[s[j]] = j`).
6. Update `ans` with the maximum length (`ans = max(ans, j - i + 1)`).
7. Return `ans`.

**Code**:

```cpp
class Solution {
public:
    int lengthOfLongestSubstring(string s) {
        int i = 0, j = 0, ans = 0, n = s.length();
        unordered_map<char, int> mp;

        for (j = 0; j < n; j++) {
            if (mp.find(s[j]) != mp.end()) {
                if (mp[s[j]] >= i) {
                    i = mp[s[j]] + 1;
                }
            }

            mp[s[j]] = j;
            ans = max(ans, j - i + 1);
        }

        return ans;
    }
};
```

**Time Complexity**: O(N)  
**Space Complexity**: O(min(N, M))

---

### **Key Takeaways**:

1. **Brute Force** checks every substring and is not efficient for long strings.
2. **Better Approach** uses the sliding window to keep track of characters, resulting in linear time complexity.
3. **Optimal Approach** further optimizes by directly jumping the start of the window to the right of the last repeated character, reducing unnecessary shifts and improving performance.
